# HPF Automation PoCs

This repository contains 5 Proof-of-Concept (PoC) automation scripts for Hasso Plattner Foundation (HPF) to demonstrate how AI and Python can reduce manual effort and improve project efficiency.

1. Grant Tracker
2. Project KPI Dashboard
3. Document Archiving
4. Deadline Reminder
5. AI-Assisted Grant Reports

See individual folders for scripts and usage instructions.
